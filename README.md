# Verilog Interpreter

Run Verilog in your browser: **https://goodman-pro.github.io/verilog-interpreter/**

Write a design and a testbench, press Run, and get the `$display` output and waveforms. The simulator is a
single dependency-free JavaScript file; nothing is installed and nothing is uploaded.

## What it is

`verilog.js` is an event-driven, 4-state (0, 1, x, z) Verilog-2001 simulator:

- **Preprocessor and lexer**: `` `define `` (with arguments), `` `ifdef/`ifndef/`elsif/`else/`endif ``, `` `timescale ``,
  `` `default_nettype ``.
- **Parser**: modules, ANSI and classic port lists, parameters, `generate` for/if/case, functions, tasks, gate primitives.
- **Elaborator**: parameter overrides, hierarchy, hierarchical names, implicit nets, constant functions.
- **Simulator**: active / inactive (`#0`) / nonblocking / postponed regions, inertial net delays with separate
  rise, fall and turn-off values, wire resolution with multiple drivers and tri-state, `wand`/`wor`,
  `tri0`/`tri1`/`pullup`/`pulldown`, two-way `inout` ports, IEEE 1364-2005 expression width and signedness rules,
  reals, memories, `automatic` tasks and functions, `fork`/`join`, and `disable` (including of a block or task
  that is running in another process).

Supported system tasks and functions: `$display $write $strobe $monitor` (and the `b/h/o` forms), `$monitoron/off`,
`$time $stime $realtime $timeformat $printtimescale`, `$finish $stop`, `$random $urandom $urandom_range $dist_uniform`,
`$signed $unsigned`, `$clog2 $bits`, `$rtoi $itor $realtobits $bitstoreal`, `$sformat $swrite`, and the real math
functions (`$sqrt $pow $ln ...`).

Not supported: `$readmemh/$readmemb` and file I/O, `` `include ``, user-defined primitives, `specify` timing, drive
strengths, `trireg`, switch primitives (`tran`, `cmos`), `defparam`, `force/release`, procedural
`assign/deassign`, arrays of instances, the raw `%u`/`%z` formats, and SystemVerilog. These report an error
instead of being silently ignored.

Where the standard leaves behaviour open (time-zero ordering, default print widths, `$random` values) the
interpreter follows [Icarus Verilog](https://steveicarus.github.io/iverilog/), so results match what most people
see locally or on EDA Playground. Known differences from Icarus:

- Arithmetic on unsized constants uses the IEEE 32-bit rule (`2147483647 + 1` is 32 bits wide); Icarus widens it.
- Recursion is limited by the JavaScript stack to roughly a thousand levels.
- Simulation time is a JavaScript number, so it is exact only up to 2^53 time-precision ticks.
- Events that happen at the same instant in different processes may be ordered differently (the standard
  allows any order). At time 0, a wire computed from not-yet-initialised signals reads `x` rather than `z`.
- `%s` prints an embedded NUL byte as a space for constants as well as for variables.

## Files

| File | Purpose |
| --- | --- |
| `verilog.js` | The whole interpreter. `Verilog.run(source, options)` returns `{output, error, errorLine, time, finished, waves}`. |
| `worker.js` | Runs the simulation in a Web Worker so the page stays responsive and Stop works. |
| `index.html` | The page: editor, examples, output console, waveform viewer. |
| `test.js` | `node test.js` runs the corpus; `node test.js file.v` runs one file. |
| `tests/` | 160 programs with expected output generated by Icarus Verilog (`tests/gen-expected.sh`). |

## Use it from Node

```js
const Verilog = require('./verilog.js');
const r = Verilog.run('module t; initial $display("%0d", 6 * 7); endmodule');
console.log(r.output);   // 42
```

Options: `maxOps` (total step budget, default 5e7), `maxStepOps` (steps allowed without time advancing, default 1e7),
`maxTime`, `maxOutput`, `waves: false` to skip waveform recording, `onOutput(text)` to stream output.

## Tests

```
node test.js
```

Every `.expected` file is the real output of Icarus Verilog 12 for the matching `.v` file. To regenerate them
(needs `iverilog` and `vvp`): `bash tests/gen-expected.sh`.

## How it was built

A collaboration between AI models, directed by the repository owner:

- **Claude** (Anthropic) wrote the interpreter, the page and this README.
- **GPT-6 Astra** (OpenAI, via Codex) wrote the first 82 conformance cases in `tests/`, independently of the
  interpreter's code, using Icarus Verilog as the oracle.
- **GPT 6.2 Astra** (OpenAI, via Codex) then reviewed the interpreter adversarially and reported 69 defects, each
  with a minimal program. A team of Claude reviewers ran a further 1,385 programs against Icarus and reported 56.
  The confirmed ones were fixed, and every repro that Icarus accepts became a regression test (cases 085–160; the
  `gpt_` and `hunt_` prefixes say who found each one).
