    Verilog Interpreter
    
  
    An event-driven, 4-state (0, 1, x, z) Verilog-2001 simulator written in plain JavaScript. Your code is simulated on this device; nothing is uploaded.
    
  
    How to use it
    
  
      
    
    • Write one or more modules. Any module that nobody instantiates is run as a top-level testbench.
      • 
    
    • Ctrl+Enter runs. End the simulation with $finish, or press Stop.
      • 
    
    • In the waveform view drag to pan, Ctrl+scroll or +/− to zoom, hover to read values. Click the panel's title to hide it and to bring it back.
      • 
    
    • The editor closes brackets and quotes, keeps your indentation, and suggests keywords, system tasks and the names in your code as you type: Tab inserts the highlighted suggestion, ↑ ↓ then Enter picks another, and Ctrl+Space opens the list.
      • 
    
    • Otherwise Tab indents; press Esc first to move focus out with Tab.
      • 
  
    
  
    Supported
    
  
    Modules, parameters and overrides, ANSI and classic port lists, generate for/if/case, hierarchical names, gate primitives, continuous assignments with rise/fall delays, tri-state and multi-driver wires, wand/wor, tri0/tri1, pullup/pulldown, inout ports, always/initial, blocking and nonblocking assignments, delays and event controls, wait, fork/join, named events, disable, functions and tasks (including automatic), memories, signed arithmetic, reals, `define/`ifdef/`timescale, and $display $write $strobe $monitor $time $realtime $timeformat $random $signed $unsigned $clog2 $bits $sformat $finish.
    
  
    Not supported
    
  
    $readmemh/$readmemb and file I/O, `include, user-defined primitives, specify timing, drive strengths, trireg and switch primitives, defparam, force/release, arrays of instances, and SystemVerilog.
    
  
    Results are checked against Icarus Verilog. Source and tests: github.com/GOODMAN-PRO/verilog-interpreter.
